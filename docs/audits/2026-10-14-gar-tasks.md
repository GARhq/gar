## Feature nova — `gar client add` / `remove` / etc (pedido 2026-10-14)

Contexto: hoje o `gar client` tem `session-doctor`, `list`, `wake`. O usuário precisa de um CRUD de clientes com **mac**, **ip**, **hostname**, **channel**, e mais atributos (a definir).

### F-1 — Definir schema do cliente
- Adicionar `src/commands/client/schema.rs` com struct `ClientSpec`:
  ```rust
  pub struct ClientSpec {
      pub mac: String,         // canonical, lowercase, sem ":"
      pub ip: IpAddr,
      pub hostname: String,
      pub channel: Channel,    // generic | lab | rescue
      pub kernel_args: Option<String>,  // cmdline extra
      pub notes: Option<String>,
  }
  ```
- **Critério de aceite:** struct serializa/deserializa YAML (formato do inventory atual).

### F-2 — `gar client add`
- **Subcomando:** `gar client add --mac <mac> --ip <ip> --hostname <name> --channel <ch> [--kernel-args <args>] [--notes <txt>]`
- **Comportamento:** valida MAC, IP e hostname (formato); insere entrada no inventory Nix; roda `gar server check --inventory <file>` para validar; emite `gar server sync` automaticamente (se `--no-sync` ausente).
- **Arquivo:** `src/commands/client/add.rs`
- **Critério de aceite:** add seguido de `gar client list` mostra a entrada nova.

### F-3 — `gar client remove`
- **Subcomando:** `gar client remove <mac|hostname>` (aceita qualquer um dos dois)
- **Comportamento:** remove entrada do inventory; roda `gar server check`; `gar server sync` opcional.
- **Arquivo:** `src/commands/client/remove.rs`
- **Critério de aceite:** remove seguido de `gar client list` não mostra mais a entrada.

### F-4 — `gar client show`
- **Subcomando:** `gar client show <mac|hostname>`
- **Comportamento:** exibe o `ClientSpec` em formato tabela ou JSON.
- **Arquivo:** `src/commands/client/show.rs`
- **Critério de aceite:** retorna dados corretos em ambos formatos.

### F-5 — `gar client update`
- **Subcomando:** `gar client update <mac|hostname> [--ip <ip>] [--hostname <n>] [--channel <ch>] [--kernel-args <args>] [--notes <txt>]`
- **Comportamento:** atualiza campos do `ClientSpec` existente. `--add-kernel-arg` e `--remove-kernel-arg` para manipulação granular de cmdline.
- **Arquivo:** `src/commands/client/update.rs`
- **Critério de aceite:** update altera o inventory e reflete no `gar client list`.

### F-6 — `gar client set-status` (online/offline/maintenance)
- **Subcomando:** `gar client set-status <mac|hostname> --status <online|offline|maintenance>`
- **Comportamento:** adiciona campo `status` ao `ClientSpec` (default: `online`).
- **Arquivo:** `src/commands/client/set_status.rs`
- **Critério de aceite:** `gar client list` mostra o status na coluna STATUS.
